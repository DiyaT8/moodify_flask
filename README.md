# Moodify Flask

Moodify is a **web application built with Flask** that detects the user's mood and recommends music accordingly. It leverages natural language processing and sentiment analysis to provide personalized music suggestions.

---

## Features

- Detects emotions from text input.
- Recommends music based on detected mood.
- User-friendly web interface.
- Supports multiple moods (happy, sad, angry, etc.).

---

## Technologies Used

- **Python** – Backend programming
- **Flask** – Web framework
- **HTML / CSS / JS** – Frontend
- **YouTube API** – Music recommendations
- **dotenv** – For managing API keys
